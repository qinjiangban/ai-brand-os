# GEO 企业版运营平台页面设计文档

## 1. 设计目标
- 在视觉上参考 `bd.qmzb168.com` 的“流程化、步骤化、数据感”表达
- 在交互上采用标准企业 SaaS 后台范式，突出可执行、可追溯、可协作
- 在技术上贴近 `Next.js`、`shadcn/ui`、`Tailwind CSS` 与 Vercel 风格生态

## 2. 全局布局

### 2.1 应用框架
- 左侧固定主导航：按业务阶段组织模块入口
- 顶部状态条：组织信息、订阅状态、当前品牌、全局搜索、个人菜单
- 主内容区：使用 12 栏网格，优先双列或三段式工作台布局
- 辅助面板：对复杂页面使用右侧详情面板或抽屉，减少页面跳转

### 2.2 全局设计令牌
- 背景色：`zinc` 深灰阶，形成专业工作台基底
- 主强调色：青蓝色，应用于主操作、焦点态、流程高亮
- 次强调色：青绿色，应用于增长、成功、已完成状态
- 风险色：红色用于错误与敏感词，琥珀黄用于待确认与告警
- 圆角：卡片 `rounded-2xl`，输入控件与按钮 `rounded-xl`
- 阴影：卡片使用低对比阴影 + 边框，避免过度浮夸
- 字体层级：页面标题、区块标题、正文、辅助信息四级体系

## 3. 导航与信息架构
| 导航分组 | 页面 | 说明 |
|----------|------|------|
| 启动 | `/dashboard`、`/billing` | 查看当前组织状态与流程起点 |
| 数据 | `/imports`、`/brand-monitor`、`/competitors`、`/statistics` | 手工导入、监测与统计 |
| 内容 | `/content-engine`、`/review`、`/publish` | 生成、审核、发布与回填 |
| 分析 | `/analytics`、`/reports` | 聚合分析与明细导出 |
| 管理 | `/ai-platforms`、`/accounts/members`、`/settings` | AI、成员、系统配置 |

## 4. 关键页面结构

### 4.1 登录与订阅
| 页面 | 区块 | 设计说明 |
|------|------|----------|
| `/login` | 品牌头图 + 登录卡片 | 左侧展示产品价值与流程插画，右侧表单强调邮箱密码登录 |
| `/set-password` | 激活流程卡 | 明确“首次激活组织账号”的状态提示 |
| `/billing/subscribe` | 套餐卡 + FAQ | 两张套餐卡并列，突出月付/年付，右侧展示能力说明 |
| `/billing` | 当前订阅信息 | 展示状态徽标、周期、续费时间、账单说明 |

### 4.2 总览页
| 区块 | 设计说明 |
|------|----------|
| 顶部 Hero | 展示当前组织、品牌、订阅状态和一句运营建议 |
| KPI 区 | 4 到 6 个核心指标：曝光、收录、线索、ROI、Token 成本、待处理任务 |
| 流程工作台 | 参考站点的步骤感，展示“导入 -> 生成 -> 审核 -> 发布 -> 分析” |
| 待办与异常 | 列出待审核内容、待回填任务、失败导入批次 |
| 最近活动 | 展示最新导入、最新发布任务、最新 AI 调用 |

### 4.3 数据导入中心
| 区块 | 设计说明 |
|------|----------|
| 导入类型切换 | 用 Tabs 展示四类导入：品牌提及、指标事件、竞品洞察、发布回填 |
| 模板说明 | 每类显示字段说明、CSV 模板下载、示例说明 |
| 上传区 | 拖拽上传 + 覆盖策略选择 |
| 批次记录 | 表格展示批次号、导入人、成功/失败行、时间、操作 |
| 失败详情 | 支持查看失败原因与下载失败行 |

### 4.4 内容生成页
| 区块 | 设计说明 |
|------|----------|
| 左侧参数面板 | 品牌、平台、关键词、内容类型、长度、语气、模型选择 |
| 中部生成工作区 | 显示提示词摘要、流式生成结果、版本列表 |
| 右侧质量面板 | 展示收录潜力、平台适配、优化建议、Token 消耗 |
| 底部资产操作 | 保存为内容资产、提交审核、版本对比 |

### 4.5 审核页
| 区块 | 设计说明 |
|------|----------|
| 原稿与建议对比 | 双栏或上下对比展示原稿和 AI 改写建议 |
| 敏感词高亮 | 用红色高亮命中词并标记等级 |
| 建议摘要 | 聚合替换建议、合规说明、命中次数 |
| 确认操作 | 明确“确认采纳后才生成新版本”主按钮 |

### 4.6 发布任务页
| 区块 | 设计说明 |
|------|----------|
| 筛选栏 | 品牌、渠道、负责人、状态、时间筛选 |
| 任务列表 | 表格或卡片展示任务、计划时间、负责人、状态 |
| 任务详情抽屉 | 展示内容资产摘要、发布时间、回填信息 |
| 回填表单 | URL、发布时间、曝光、互动、线索、转化、ROI |

### 4.7 分析与报表
| 页面 | 区块 | 设计说明 |
|------|------|----------|
| `/analytics` | 指标卡 + 趋势图 + 分布图 | 强调收录、曝光、线索、ROI、Token 成本联动 |
| `/reports` | 筛选器 + 明细表格 | 支持多维筛选、排序、CSV 导出 |
| `/statistics` | 组织级汇总 | 看板化展示导入、生成、审核、发布、AI 成本整体表现 |

### 4.8 管理与设置
| 页面 | 区块 | 设计说明 |
|------|------|----------|
| `/ai-platforms` | AI Key 管理 + 默认模型配置 | 分区展示可用模型、模块默认模型、任务级覆盖规则 |
| `/accounts/members` | 成员表格 + 邀请弹窗 | 展示角色、状态、加入时间，支持邀请与禁用 |
| `/settings` | 组织信息 + 敏感词词库 | 支持词库导入、编辑、启停与系统参数设置 |

## 5. 状态设计
- 空状态：每个业务页都提供“下一步推荐动作”，避免空白
- 加载状态：用骨架屏和分栏占位，保持后台的稳定感
- 成功状态：使用青绿色徽标和轻提示，不弹过多模态窗
- 异常状态：导入失败、Webhook 失败、回填缺失等通过顶部告警和表格状态并存
- 权限状态：只读角色隐藏编辑操作，并在页面头部给出权限说明

- `DataTable`：统一表格

- `EmptyState`：空状态引导
- `MetricTrendChart`：趋势图
- `ImportDropzone`：上传拖拽区
- `RevisionDiffPanel`：版本对比面板

## 7. 与参考站点的取舍
- 保留：流程分阶段表达、模块清晰入口、数据结果导向
- 调整：去掉偏营销宣传和合规告知首页，改成登录后工作台优先
- 增强：增加组织、角色、订阅、RLS、批次追溯、审计和 AI 成本记录
- 约束：不实现自动发布和真实平台账号接管，只做任务编排与回填闭环
